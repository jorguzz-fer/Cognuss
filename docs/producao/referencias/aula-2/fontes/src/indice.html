Fisiologia do eixo somatotrófico

Os 27 slides desta aula não trazem pedidos de peça, então as peças foram propostas a partir do conteúdo: os mecanismos que mudam com o tempo viraram simuladores e o diagnóstico virou casos interativos. Cada peça é uma página independente.
