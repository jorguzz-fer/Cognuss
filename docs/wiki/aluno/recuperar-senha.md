# Como recuperar a senha

Quando você esquece a senha, o Cognuss envia um link para criar uma nova.

**Quem pode:** qualquer pessoa com conta, sem login. **Onde:** `/recuperar-senha` (na tela **Entrar**, link **Esqueci minha senha**) e `/redefinir-senha`, aberta pelo link do e-mail.

**Chave de módulo:** nenhuma.

## Passo a passo

1. Na tela **Entrar**, clique em **Esqueci minha senha**.
2. Na tela **Recuperar senha**, digite o e-mail em **E-mail da conta**.
3. Clique em **Enviar link**.
4. Abra o e-mail com o assunto **Redefina sua senha do Cognuss** e clique em **Criar nova senha**. O link vale por 1 hora.
5. Na tela **Criar nova senha**, digite a senha nova em **Nova senha** (pelo menos 8 caracteres).
6. Clique em **Salvar nova senha**.

## O que acontece depois

- A plataforma volta para **Entrar**, com o aviso "Senha redefinida. Entre com a senha nova." Entre com a senha nova.
- Ao salvar, você sai de todos os aparelhos em que estava conectado. É o aviso do campo: "Ao salvar, você sai de todos os aparelhos."
- A tela de recuperação sempre mostra "Se houver uma conta com esse e-mail, você vai receber um link para criar uma nova senha. Ele vale por 1 hora.", exista a conta ou não. É proteção contra quem tenta descobrir e-mails cadastrados.

## Se der errado

| Mensagem                                                                    | O que fazer                                                                                                            |
| --------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| "Muitas tentativas. Espere alguns minutos."                                 | O limite é de 5 pedidos a cada 5 minutos. Aguarde.                                                                     |
| "Esse link expirou ou é inválido. Peça um novo."                            | Clique em **Peça um novo** e repita o pedido.                                                                          |
| "Esse link expirou ou já foi usado. Peça um novo em "Esqueci minha senha"." | O link vale uma vez só e por 1 hora. Peça outro.                                                                       |
| "A senha precisa de pelo menos 8 caracteres."                               | Use uma senha mais longa.                                                                                              |
| O e-mail não chega                                                          | Confira spam e promoções. Confira se o e-mail é o mesmo da conta. O suporte pode confirmar no admin se a conta existe. |
