# Como criar um assunto (e um subassunto)

Cria um assunto dentro de uma disciplina, por exemplo "Ciclo cardíaco" em Fisiologia. Assuntos organizam módulos e questões. Um assunto pode ficar dentro de outro, como subassunto.

**Quem pode:** Admin. **Onde:** Admin → Cursos → curso → disciplina, seção **Assuntos**, `/admin/disciplinas/<disciplina>`.

## Antes de começar

- A disciplina precisa existir. Veja [Adicionar uma disciplina](adicionar-disciplina.md).
- Para um subassunto, crie antes o assunto principal.

## Passo a passo

1. Abra a disciplina: **Cursos** → curso → nome da disciplina.
2. Na seção **Assuntos**, vá até o formulário no fim do quadro.
3. Em **Novo assunto**, escreva o nome.
4. Em **Dentro de** (opcional), escolha:
   - **Nenhum (assunto principal)** para um assunto de primeiro nível;
   - o nome de um assunto principal para criar um subassunto dentro dele.
5. Clique em **Adicionar**.

## O que acontece depois

- Aparece o aviso "Assunto criado.".
- O assunto entra na lista com **Ordem** 0. Para mudar a posição, veja [Renomear ou reordenar um assunto](editar-assunto.md).
- Subassuntos aparecem logo abaixo do assunto principal, recuados.
- Só existe um nível de aninhamento: o campo **Dentro de** mostra apenas assuntos principais.
- Depois de criado, o assunto não muda de lugar. A tela não tem campo para trocar o assunto principal. Se errou, exclua e crie de novo (enquanto ele não tiver questões).
- O assunto passa a aparecer no campo **Assunto** de módulos e de questões. Nas listas, subassuntos aparecem com um traço na frente do nome.
- Para o aluno, um módulo ligado a um assunto principal também traz as questões dos subassuntos.

## Se der errado

- "Dê um nome ao assunto.": o nome precisa de pelo menos 2 caracteres.
- "Já existe um item com esse nome ou endereço.": a disciplina já tem um assunto com esse nome.
