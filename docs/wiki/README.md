# Wiki do Cognuss

Como fazer cada ação na plataforma, passo a passo. Cada página diz quem pode, em que tela, os passos com os nomes exatos dos botões, o que acontece depois e o que fazer se der errado.

As páginas foram escritas a partir do código. O que não deu para confirmar está marcado como "(a confirmar)". Quando uma tela mudar, atualize a página junto, no mesmo PR.

Para a visão de cima (quem faz o quê), veja o mapa de atores em `/mapa` no app (fonte em `docs/mapa/`).
